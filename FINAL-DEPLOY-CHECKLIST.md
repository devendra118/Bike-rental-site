# Hari Rental Services — Final Deployment Checklist

## Upload this folder
Upload the contents of this folder to your GitHub repository root. `index.html` must be at the root.

## Netlify
1. Connect the GitHub repository.
2. Build command: leave blank.
3. Publish directory: `.` (repository root).
4. Deploy.
5. Test Home → Quick Booking, Bikes → Enquire, and Contact → Send Enquiry.
6. Check Netlify → Forms for `home-booking-enquiry`, `booking-enquiry`, and `contact-enquiry`.

## Important
Forms require the deployed Netlify site; they will not deliver submissions when HTML is opened with `file://`.
